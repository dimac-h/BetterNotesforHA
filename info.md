# Better Notes for Home Assistant

Transform your Home Assistant experience with Better Notes - an Apple Notes-inspired integration that brings elegant, intuitive note-taking to your smart home.

## Key Features

- **Beautiful Apple Notes-like Interface** - Enjoy a clean, modern UI that's both powerful and easy to use
- **Sidebar Integration** - Access your notes instantly from the Home Assistant sidebar
- **Dashboard Cards** - Pin notes or note lists to any dashboard for quick reference
- **Smart Organization** - Use colors, pins, and tags to keep your notes organized
- **Auto-Save** - Never lose your work with automatic saving as you type
- **Powerful Search** - Find any note instantly with real-time search
- **Automation Ready** - Create and manage notes programmatically with built-in services

## Perfect For

- Shopping lists and grocery tracking
- Family message boards
- Home maintenance checklists
- Quick reminders and to-dos
- Automation-generated notifications
- Doorbell and visitor logs
- Daily routines and schedules
- Any note-taking needs in your smart home

## Quick Start

1. Install via HACS
2. Restart Home Assistant
3. Add the Better Notes integration
4. Start taking notes from the sidebar
5. Pin note cards to your dashboards

## Service Integration

Better Notes integrates seamlessly with Home Assistant automations. Create notes automatically when events occur, update shopping lists with voice commands, or delete old reminders on a schedule.

Example: Create a note when someone rings your doorbell with the timestamp and camera snapshot reference.
